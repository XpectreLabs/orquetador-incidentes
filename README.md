#  Orquestador de Incidentes — Ancla Sistemas

> Triage + runbook autónomo (reinicio/rollback) con trazabilidad.

## ¿Qué es?

Sistema inteligente de respuesta a incidentes que automatiza el proceso de triage, ejecución de runbooks y auditoría de acciones correctivas.

## Características

-  **Cola de tickets** — Ingesta y priorización automática de incidentes
-  **Triage automático** — Clasificación por severidad y tipo usando IA
-  **Runbooks autónomos** — Ejecución de reinicio, rollback y escalado
-  **Timeline auditable** — Trazabilidad completa de cada remediación

## Stack

- **Backend**: Node.js / Python
- **Frontend**: HTML + CSS + JavaScript
- **IA**: Claude (Anthropic)
